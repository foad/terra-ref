# terra-ref

Showcase page for [TERRA](https://github.com/foad/terra), served at https://terra.foad.dev.

```bash
npm install
npm run dev
npm run build
```

Deploys to GitHub Pages via `.github/workflows/deploy.yml` on push to `main`. Repo settings: Pages source = GitHub Actions, custom domain `terra.foad.dev`. DNS: `terra` CNAME `foad.github.io`.
